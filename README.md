

### 🌦️ Project Overview
A responsive React weather application that provides real-time data and adaptive travel advice.

### 🚀 Features
- **Smart Search:** Handles City names, Towns, and Zip Codes.
- **Resilient UI:** Includes a **Mock Data Fallback** to ensure the app is usable even during API activation delays.
- **Innovative "Traveler Tip":** Provides adaptive packing and safety advice based on weather conditions.
- **5-Day Forecast:** Clean grid display of upcoming weather.

### 🛠️ Tech Stack
- React + Vite
- OpenWeatherMap API
- CSS Flexbox/Grid for Responsive Design
